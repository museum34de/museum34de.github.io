常见问题 (FAQ)

CS1.6 单机版支持多人联机吗？
本下载包主要包含单机离线版本。如需多人联机，需拥有原始Steam版本的CD-KEY并配合SteamPipe更新器进行配置。
游戏声音正常但画面全黑怎么办？
请尝试在游戏快捷方式的目标栏末尾添加 `-console` 参数，然后在游戏内按 `~` 键打开控制台，输入 `vid_restart` 重置显示模式。
如何增加电脑人机的难度？
进入游戏后，点击“开始游戏”，在玩家列表设置中，将Bot难度调整为“困难”或“专家”，并开启“射击技巧”选项。
游戏无法启动或报错怎么办？
请确保您的操作系统为 Windows XP / 7 / 8 / 10 / 11。如果使用 Windows 10/11，建议以兼容模式运行游戏。
